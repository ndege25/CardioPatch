# CardioPatch

### A Low-Cost Wearable Cardiorespiratory Monitoring and Remote Patient Surveillance System

## Overview

CardioPatch is a proposed wearable patient-monitoring system designed to support continuous physiological surveillance and remote monitoring of post-operative patients and individuals with existing cardiac conditions or other cardiorespiratory monitoring needs.

The system aims to monitor physiological parameters, display patient information and simulate alerts when concerning changes are identified, supporting timely communication with healthcare providers.

## Objectives

* Explore accessible wearable cardiorespiratory monitoring.
* Develop a digital platform for visualizing physiological data.
* Demonstrate simulated patient alerts and escalation workflows.
* Establish a foundation for future hardware development and validation.

## Current Development Stage

The initial prototype is a software-based proof of concept using simulated physiological data. It is not a diagnostic tool or a clinically validated medical device.

## Future Development

* Integration of physiological sensors.
* Development of a wearable prototype.
* Wireless data transmission and mobile monitoring.
* Technical and clinical validation.
